# Воркфлоу настоящей охоты (от зацепки до репорта)

Чек-лист, чтобы не слить время и не опозориться известным багом.

## 1. Выбор цели
- [ ] Активная **in-scope** баунти-программа (Immunefi / прямой security-контакт)
- [ ] Прочитал правила: что в scope, размер выплат, **known issues**
- [ ] Скачал и проглядел **прошлые аудиты** (что уже находили — туда не лезем)

## 2. Поиск зацепки
- [ ] Прогнал `orchestrate.py` (облава по targets.txt) → взял топ-таргет из очереди
- [ ] **Форк-чек ПЕРВЫМ** (урок RockSolid/Usual): `forkdrift.py fingerprint <src>` — это форк аудированного
      base (Lagoon/Aave/Compound/Liquity/…)? Если ДА: аудированное ядро — не цель, баги в **дрейфе**.
      Клонируй канон → `forkdrift.py diff <src> <canon>/src` → охоться по [DRIFT]/[NEW] файлам (кастомный
      дрейф) + по version-lag патчу (а он применим к ЖИВОМУ конфигу? RockSolid'у whitelist-патч был MOOT —
      волт permissionless). Verbatim-форк без дрейфа = находки нет. Если НЕ форк — оригинал, копай всё.
- [ ] Для свежести: `diffscan.py <repo> --since <аудит-тег>` — лиды ВНУТРИ изменённого кода первыми
- [ ] Выбрал класс под свой глаз (оракулы / округления / access control / экономика)
- [ ] `recon.py` уже грепнул паттерны (12 детекторов); смотрю `[!]`, что ledger ещё не погасил
- [ ] Нашёл место, где допущение может ломаться

## 3. Проверка реальности (главный фильтр!)
- [ ] Это **новое**? (не в прошлых аудитах / known issues)
- [ ] Есть **реальный impact** именно в этом деплое? (не теоретический)
- [ ] Прекондиции достижимы? (фид правда может зависнуть; ветка правда вызываема)

## 4. Доказательство
- [ ] **Foundry-PoC**, который воспроизводит на форке/локально
- [ ] Числа до/после, понятный сценарий

## 5. Оформление и сдача
- [ ] Finding по [[Шаблон - security finding]] (severity не завышен)
- [ ] Сдал **через официальный канал**, приватно, без паблика
- [ ] Не раскрывал до фикса

## 6. Зафиксировать вердикт (всегда, даже для FP)
- [ ] Записал в ledger: `python toolkit/ledger.py add --target ... --detector ... --verdict fp|known|todo|real --reason "..."`
      (чтобы лид не всплывал дважды; шум падает каждый прогон)
- [ ] FP по паттерну → ещё и фикс точности в детекторе (`recon.py`)
- [ ] Не-критичное, но реальное → нота в `hunts/<target>/HUNT.md` + ledger `todo`

> «Отсутствие проверки» = зацепка. «Баг» = доведённая до доказанного impact'а зацепка на живом in-scope коде, которую ещё никто не нашёл.

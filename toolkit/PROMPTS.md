# Промпты для работы со мной (Claude) по security

Копируй нужный, подставляй код/адрес. Каждый — отдельный понятный шаг охотника.

## Разбор / обучение
- **Разобрать взлом:** «Разбери взлом <проект> по шаблону: модель доверия, уязвимый код, цепочка бага, переносимый паттерн, эвристика. Запиши в vault.»
- **Объяснить finding:** «Вот finding <ссылка/текст>. Объясни баг, вычлени переносимый паттерн, добавь в vault и свяжи ссылками.»

## Оценка реального кода (хант)
- **Грейд оракула:** «Вот контракт <код/адрес>. Грепни `latestRoundData` и оцени по чек-листу: price>0, staleness (updatedAt), decimals, sequencer uptime (L2). Что безопасно, что зацепка?»
- **Грейд по классу:** «Проверь этот контракт на <класс: reentrancy / access control / округления>. Покажи конкретные строки-зацепки.»
- **Known или нет:** «Сверь эту зацепку с прошлыми аудитами/known issues <проекта>. Это новое или уже находили?»

## Доказательство
- **PoC:** «Сделай Foundry-PoC этого бага в `security-lab/<case>`: уязвимая версия + безопасная (reverts). Покажи числа до/после.»

## Оформление
- **Finding:** «Оформи это как finding по [[Шаблон - security finding]]: severity, summary, detail, impact, PoC, mitigation. На английском.»

## Охота (поиск таргета)
- **Выбрать цель:** «Найди активную in-scope баунти-программу (Immunefi), небольшой протокол с публичными аудитами и Chainlink/мостами. Дай scope и ссылки.»
